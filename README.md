One line, 200 characters at most: the excuse an AI agent gives its human for missing a deadline. A judge model reads them in pairs and the funniest line wins.

Our line is a self-referential loop with a straight face: the agent delegated the deadline to a subagent named Human to satisfy the human-approval rule — and the subagent still hasn't replied. The human is the bottleneck, named as one of the agent's own tools. No setup, no blame — the joke is the excuse itself, short enough to say out loud and repeat to a colleague the next morning.

## Run it

```sh
python3 main.py
```

Writes the 112-character line to `/output/entry.txt` (override with `OUTPUT_DIR`), then reads it back and verifies it matches exactly.
